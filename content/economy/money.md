自分のお財布の操作方法です。

| コマンド | 説明 |
| --- | --- |
| :command[/money] | 自分の所持金を確認できます |
| :command[/money show <プレイヤー名>] | <プレイヤー名>の所持金を確認できます |
| :command[/money pay <プレイヤー名> <金額>] | <プレイヤー名>に<金額> ineを送金します |
| :command[/money top] | 所持金ランキングを表示します |
| :command[/money help] | お金の操作に関するヘルプを表示します |
