このページでは、いねさばで道路や鉄道を作るときの決まりと、登録の方法を説明します。

なお、危険な交通施設や景観を損なう交通施設の撤去・改修については、登録の有無にかかわらず[サーバールール](/server-guide/rule)が適用されます。先にそちらをご確認ください。

# このページの概要
このページで述べられていることを以下の表に簡単にまとめました。

| 作るもの | 登録 | 長さ | 主な規格 |
| :--- | :--- | :--- | :--- |
| <span style="white-space: nowrap;">**生活道路**</span>（第3種道路） | 不要 | 500マス未満 | 幅員 6マス以下 |
| <span style="white-space: nowrap;">**登録しない線路**</span> | 不要 | 500マス未満 | マップには載りません |
| <span style="white-space: nowrap;">**地域道**</span>（第2種道路） | **必要** | 段階1：500マス未満<br>段階2から：制限なし | 幅員 9マス以上 |
| <span style="white-space: nowrap;">**鉄道**</span> | **必要** | 段階2：1区間（1000ブロック未満）<br>段階3：制限なし | 敷地 5ブロック以上 |
| <span style="white-space: nowrap;">**国道**</span>（第1種道路） | 運営の事業 | － | 幅員 19マス以上 |

※ 工場・商業施設内などの<span className="text-red">**敷地内の道路や線路については「敷地内の私道」などの扱いのため、このガイドラインには当てはまりません。**</span> あくまでも、このガイドラインは公共の道路・鉄道としてのものです。

# 1. はじめに

いねさばでは、短い道路や線路は誰でも自由に作ることができます。長い道路や鉄道を作りたい場合は「登録」をしてください。

登録の目的は以下の2つです。

- 道路に番号を付けること
- 鉄道をマップに載せること

登録した道路は「公共事業」です。道路敷設後は運営へ寄贈される形になります。なお、登録した道路の0kmポスト（起点）付近には道路の設計者を表す看板を設置します。

また、登録をする全ての方は「延伸・改修・改良」・「交差道路」を参照し、同意してから計画を始めてください。運営は仮登録をした時点でこのガイドラインの内容に同意したものとみなします。

※ 運営の事業（国道の敷設、中央線の延伸など）は、このページの登録や段階の対象外です。

# 2. 登録しなくても作れるもの

## 生活道路（第3種道路）
いわゆる、公共の私道（高速道路を除く）や里道、裏道、生活道路はこちらを指します。

- 幅員は6マス以下（1車線道路）を基本としてください。
- 500マス以上の長距離延伸は禁止です。（サラミ戦術（分割建設）も禁止です。発見し次第撤去します。）
- 道路の資材は問いませんが、「道路」だと分かるように努めてください。
- 大規模な地形改変は避けてください。あくまでも地形に沿った道路でお願いします。

## 登録しない線路
- 500マス以上の長距離延伸は禁止です。（生活道路と同じく、分割建設も禁止です。）
- 登録しない線路はマップや路線図には載りません。路線記号や駅番号も付きません。
- 大規模な地形改変は避けてください。

なお、どちらも特別な申請などは不要です。サーバールールに従って建設をお願いします。

# 3. 登録の段階
登録には3つの段階があります。段階が上がるごとに、作れるものが増えていきます。

| 段階 | 作れるもの | 仮登録の条件 |
| :--- | :--- | :--- |
| **段階1** | 地域道（500マス未満） | プレイ時間 10 時間 |
| **段階2** | 地域道（長さの制限なし）<br>鉄道 1区間（1000ブロック未満） | 段階1の登録 |
| **段階3** | 鉄道（長さの制限なし） | 段階2の鉄道の登録 |

- 駅の前には道路が必要になるため、鉄道を作りたい方もまずは道路から始めていただきます。
- プレイ時間は[実績](/adventure/achivements)で測ります。放置（AFK）している時間は含まれません。実績の導入以前から参加されている方は、運営までご相談ください。
- トリロジーの道路・鉄道の機能を使う場合は、別に称号：[住民]（プレイ時間 50 時間）が必要です。詳しくは[トリロジー](/life/trilogy)をご覧ください。
- 段階が上がるのは完成後の「登録」がされたときです。仮登録だけでは上がりません。
- 鉄道の「1区間」とは、駅と駅の間ひとつ分（2駅）のことです。
- 複数人で作った場合、段階が上がるのは代表者だけです。

# 4. 登録の流れ
登録は着工前の「仮登録」と完成後の「登録」の2回です。どちらも[道路・鉄道申請チャンネル]に投稿してください。

| | いつ | 運営が確認すること |
| :--- | :--- | :--- |
| **仮登録** | 着工前 | 段階の条件を満たしているか、計画が適切か |
| **登録** | 完成後 | 規格どおりに、適切にできているか |

登録がされると、道路には番号が付き、鉄道はマップに載ります。

## 計画の条件
- 少なくとも片方の端は「国道」・「登録済みの地域道」・「駅」のいずれかにつないでください。
- 鉄道の場合、既にある鉄道（仮登録中のものを含む）と並行する計画は認められません。（一部区間が並行するなどの場合は要検討です。ご連絡ください）
- 同時に持てる仮登録は1人につき1つです。
- 仮登録の後に経路を大きく変える場合は、仮登録を出し直してください。
- 他のプレイヤーの保護領域の近くを通る場合は、サーバールールに従って、所有者の許可を得てください。

## 仮登録の有効期間
- 仮登録の有効期間は3ヶ月程度です。
- 期間内に完成しない場合は、進み具合が分かる画像を添えて、申請チャンネルで延長を申し出てください。前回から工事が進んでいれば延長します。延長の回数に制限はありません。
- 延長の申し出がない場合や、工事が進んでいない場合は、仮登録が失効します。
- 失効しても、段階が下がることはありません。
- 失効した区間は、他のプレイヤーが仮登録できるようになります。未完部分については撤去、または運営が引き継ぐものとします。なお、使用された資材の返還は行いません。

# 5. 地域道（第2種道路）の規格
**「地域道〇〇〇号線」** と、番号が振られる道路です。

## 道路の最小要件
- 幅員は9マス以上（道路部分4マス+線+道路部分4マス）にしてください。（片側1車線道路以上）
- 道路の端には脱輪防止のためのガードレール（ハーフブロックなどでも可）を設置してください。
- 追加で、歩道をガードレールの外側に3マス以上設置してください。なお、歩道は片側だけでも構いません。
- やむを得ない事情や計画上歩道を設置できない場合は、歩道だけの迂回路を設置してください。
- 道路の建材は「青緑色のテラコッタ」・「白色のコンクリート」・「赤い砂岩」に統一してください。
- 大規模な地形改変は避けてください。あくまでも地形に沿った道路でお願いします。

## 道路番号と道路名
道路番号は以下の通り付与されます。

※カテゴリ内の各番号は計画順で付与されます。

|道路番号|方角|
|---|---|
|100-200番台|始点が国道1号線から国道2号線の内部（ざっくり西側）|
|300-400番台|始点が国道2号線から国道3号線の内部（ざっくり北側）|
|500-600番台|始点が国道3号線から国道4号線の内部（ざっくり東側）|
|700-800番台|始点が国道4号線から国道5号線の内部（ざっくり南側）|

道路名は仮登録のときに運営と協議して決定します。

# 6. 鉄道の規格

## 鉄道の最小要件
- 鉄道用の敷地は単線の場合5ブロック以上（侵入防止柵1ブロック+間隔1ブロック+レール1ブロック+間隔1ブロック+侵入防止柵1ブロック）、複線の場合は7ブロック以上（レールとレールの間に1ブロックの間隔）などとしてください。
- 駅の数は1000マスに1駅程度にしてください。
- できるだけ直線的にしてください。
- 国道及び地域道とは連続立体交差を基本としてください。

## 路線記号と駅番号
- 路線にはアルファベット2文字の路線記号を付けます。仮登録のときに希望を出していただき、運営と協議して決定します。
- 運営の路線で使っている記号（CW・CE・CK・NB・N）と、既に登録されている記号は使えません。
- 駅番号は「路線記号＋2桁の数字」で、起点側から順に01、02…と付与されます。
- 路線の色も仮登録のときに希望を出すことができます。

# 7. 国道（第1種道路）
**「国道〇〇号線」** と、番号が振られる道路です。国道は運営の事業として敷設します。プレイヤーが登録して敷設することはできません。

「ここに国道が欲しい」といった希望がある場合は、運営までご連絡ください。

# 8. 延伸・改修・改良
道路は運営へ寄贈となりますが、敷設者は運営に申し出ることで、道路の延伸や改修・改良ができます。

他のプレイヤーが延伸・改修・改良を希望する場合は、一度、敷設者に提案してください。もし、折り合いがつかない場合は運営の判断となります。

また、敷設者が最終ログインから90日以上経過した場合、他のプレイヤーも敷設者の許可なく、延伸や改修・改良ができるようになります。（サーバールール参照）

ただし、運営が必要だと判断した場合、敷設者への通知なく運営もしくは第三者が延伸・改修・改良を行う可能性があります。

# 9. 交差道路
交差道路や始点・終点部に道路がある場合、その道路の敷設者に**許可を貰う必要はありません。** （計画段階での運営判断となります）

また、その交差点名に関しては運営判断とさせていただきます。予めご了承ください。

# 10. テンプレート
以下のテンプレートをコピーして、[道路・鉄道申請チャンネル]に投稿してください。

## 地域道の仮登録
```
**【地域道 仮登録】**
**仮称・道路名：** 〇〇線
**代表者MCID：**
**一緒に作る人のMCID（いれば）：**
**現在の段階：** 段階〇
**経路の座標リスト：**
- 始点：x, z
- 中継点(もしあれば)：x, z
- 終点：x, z
**全長(概算)：** 約 〇〇マス
**つなぐ国道・地域道・駅：**

**要件チェック：**
- [ ] 幅員・建材の規定を守りますか？
- [ ] 寄贈後、運営や他者による改変に同意しますか？
**マップで経路を示した図を添付してください。**
```

## 鉄道の仮登録
```
**【鉄道 仮登録】**
**路線名：** 〇〇鉄道 〇〇線
**希望する路線記号：** （アルファベット2文字）
**希望する路線の色：**
**代表者MCID：**
**一緒に作る人のMCID（いれば）：**
**現在の段階：** 段階〇
**駅（起点から順に）：**
- 駅名（よみ）：x, z
- 駅名（よみ）：x, z
**単線・複線：**
**全長(概算)：** 約 〇〇ブロック
**つなぐ国道・地域道・駅：**

**要件チェック：**
- [ ] 並行する鉄道はありませんか？
- [ ] 立体交差・柵の設置など、規格を守りますか？
**マップで経路を示した図を添付してください。**
```

## 完成後の登録
```
**【完成の報告】**
**仮登録した名前：**
**代表者MCID：**
**始点・終点の座標：** x, z ／ x, z
**駅の座標（鉄道の場合・起点から順に）：**
- 駅名：x, z
**完成した様子が分かる画像を添付してください。**
```

## 延長の申し出
```
**【仮登録の延長】**
**仮登録した名前：**
**代表者MCID：**
**前回からの進み具合が分かる画像を添付してください。**
```
