# スキルシステム (mcMMO)

日々の行動（採掘、伐採、戦闘など）に熟練度システム「mcMMO」が導入されています。
スキルごとに経験値がたまってレベルが上がり、ドロップ量が増えたり、便利な「アクティブスキル」が使えるようになります。

このサーバーでは、スキルレベルが **最大 1000** までのスケール（レトロモード）で設定されています。

# 1. パワーレベル

**全スキルのレベルの合計**が「パワーレベル」です。`/mcstats` で確認できます。
（サルベージと精錬はほかのスキルから自動で決まるため、パワーレベルには含まれません）

パワーレベルが一定に達すると、以下が解放されます。

| パワーレベル | 解放されるもの |
| --- | --- |
| 100 | 称号［スキル：ウッド］ |
| 500 | 称号［スキル：ストーン］ |
| 1,000 | 称号［スキル：アイアン］ |
| 2,000 | 称号［スキル：ゴールド］、競馬の馬主資格 |
| 3,500 | 称号［スキル：ダイヤモンド］ |
| 6,000 | 称号［スキル：エメラルド］ |
| 10,000 | 称号［スキル：ネザライト］ |
| 20,000 | 称号［？？？］ |

- 称号については[実績・称号システム](https://www.1necat.net/adventure/achivements)をご覧ください。
- 馬主については[競馬](https://www.1necat.net/adventure/horse-racing)をご覧ください。

# 2. 経験値について

## 必要経験値

次のレベルに必要な経験値は、**1,020 ＋ 20 × 今のレベル** です。
（例：Lv 0 → 1 は 1,020 XP、Lv 100 → 101 は 3,020 XP）

## 経験値ボーナス

| 方法 | 効果 | 入手・条件 |
| --- | --- | --- |
| [はじまりのテセラ](https://www.1necat.net/adventure/tessera) | 1.5倍（パワーレベル 2,000 まで） | チュートリアルから入手できます。`/tessera` でセットしている間有効 |
| mcMMO経験値ブースト券 | 1時間 2倍 | [冷めたハートをコジャクでぶち抜いて！熱く燃える秋の味覚ガチャ](https://www.1necat.net/announcements/20261002)から入手可能。複数使うと時間が延長されます |
| パーティー | 最大 1.5倍 | 75マス以内に仲間がいるとき（「6. パーティーシステム」参照） |

ボーナスは重ねて使うことができます。

## 経験値の獲得制限（減衰）

長時間同じ作業を繰り返して放置稼ぎなどを行うのを防ぐため、**「経験値の減衰システム」** を導入しております。

- **制限のルール:**
  - 各スキルごとに、**10分間で 20,000 XP** を超えて稼ぐと、それ以降の獲得量が大幅に減ります（通常の5%になります）。

制限にかかった場合、10分ほど時間を空けてください。その間、他のスキル上げをすることは可能ですが、制限時間は短縮されません。

## 💡 レベル上げのコツ

- **レベルの低いスキルほど少ない経験値で上がります。** 必要経験値はレベルとともに増えるため、たとえば Lv 0 → 100 は約20万 XP ですが、Lv 400 → 500 は約100万 XP かかります。パワーレベルは全スキルの合計なので、まだ上げていないスキルに手を広げると、パワーレベルは早く伸びます。
- **減衰はスキルごとに数えられます。** 1つのスキルを続けるより、いくつかのスキルを交代で上げると制限にかかりにくくなります。
- **経験値ボーナスは重ねられます。** テセラ・ブーストチケット・パーティーを組み合わせると効率が上がります。
- 各スキルの経験値の稼ぎ方は、「4. スキル一覧」の **経験値：** の欄をご覧ください。

# 3. アクティブスキルの使い方

「採掘」や「木こり」などのアクティブスキルは、**対応するツールを持って右クリック**し、「**斧を準備した。**」などのメッセージが出た状態でブロックを壊す（または攻撃する）と発動します。
一度使うとクールタイム（再使用待ち時間）が発生します。

# 4. スキル一覧

ゲーム内の表示（:command[/mcstats]）と同じく、収集・戦闘・その他の3つに分かれています。
各スキルの今のレベルでの効果は、`/採掘` のように :command[/スキル名] で確認できます（`/mining` のような英語名でも使えます）。

# 6. パーティーシステム (Party)

mcMMOのパーティー機能を利用すると、冒険がより有利になります。

:command[/party create <名前>] でパーティーを作成できます。

## パーティーの仕様

- **フレンドリーファイア**: 無効（メンバー同士はダメージを受けません）
- **人数制限**: なし
- **自動除名**: 7日間ログインがないメンバーは自動的にキックされます。

## 経験値ボーナス (Sharing)

パーティーメンバーが **75マス以内** にいる場合、獲得経験値にボーナスがつきます。

- **基本ボーナス**: 1.1倍
- **人数ボーナス**: メンバー1人につき +0.05倍 (最大 1.5倍)

## パーティーレベルと機能解放

メンバーが経験値を稼ぐことでパーティー自体のレベルが上がります（上限 Lv 10）。

レベルに応じて以下の機能が解放されます。

| Lv | 解放機能 | 説明 |
| --- | --- | --- |
| **1** | チャット | :command[/p] でパーティーチャットが利用可能になります。 |
| **2** | テレポート | :command[/ptp] でメンバーへのテレポートが可能になります。 |
| **5** | 同盟 | 他のパーティーと同盟を結べるようになります。 |
| **8** | アイテムシェア | アイテムの分配設定が利用可能になります。 |
| **10** | XPシェア | 経験値の分配設定が利用可能になります。 |
