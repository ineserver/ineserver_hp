いねさばには「グローバルチャット」・「ローカルチャット」・「チャンネルチャット」・「ダイレクトメッセージ」の4種類のチャットがあります。

# グローバルチャット・ローカルチャット
**グローバルチャット** とは、いねさば参加時に全員が入っているチャットです。

Discordや公式マップなどにも内容が送信されます。

挨拶や全員と雑談したい場合にはここに送信しましょう！

**ローカルチャット**とは、近辺100m以内にいる人に向けたチャットです。

それ以外の場所には内容は送信されません。

ご近所さんやラウンジなどで集まる時に使うのがオススメです。

ローカルチャットは:command[/ch local]で発言先を切り替えられます。

`/ch local`で切り替えたあと、普通に発言をすると、「周囲」と表示され、ローカルチャットで話していることになります。

グローバルチャットに戻りたい場合は:command[/ch global]から戻れます。

なお、1行だけグローバルチャットに送信したい場合は`!<グローバルチャットに送りたい内容>`でそのままグローバルチャットに送信できます。挨拶などはこれを使うのがオススメです！

# チャンネル
特定のグループでチャットをしたい場合は「チャンネルチャット」がオススメです。

## チャンネルの入り方
既にチャンネルがある場合は、:command[/ch join <チャンネルID> <パスワード(※省略可)>]からチャンネルに入ることができます。

※ パスワードは設定されていない場合、入力する必要はありません。

グローバルチャットに戻りたい場合は:command[/ch global]から戻れます。（1行だけグローバルチャットに送信したい場合は`!<グローバルチャットに送りたい内容>`でそのままグローバルチャットに送信できます。）

グローバルチャットに戻ったあと、再びそのチャンネルで発言したい場合は:command[/ch <チャンネルID>]で発言先を切り替えられます。

## チャンネルの作り方
これからチャンネルを作りたい場合は:command[/ch create <チャンネルID> <パスワード(※省略可)>]で作れます。

※ `<チャンネルID>`には、「英小文字・数字・アンダーバー・ハイフン」を利用できます。（2～16文字）

※ チャンネルは最大3つまで作成可能です。（参加できるチャンネル数に上限はありません）

他の人を誘いたい場合は上の「チャンネルの入り方」を参照してください。（チャンネルIDが必要です）

### チャンネル設定
チャンネルの作成者は「チャンネルのオーナー（管理者）」となり、チャンネルの様々な設定ができるようになります。

チャンネルの設定を変える場合は:command[/ch set <チャンネルID> <項目> [値]]からそれぞれの変更ができます。

※ `<項目>`には以下のタイトル右側にある英語が入ります。

#### チャンネル名の変更 (name)
**チャンネルの表示名**を変えることができます。

ここで変更した「チャンネル名」は`/ch list`やチャンネル内のチャットで、名前の左に表示されるチャンネル名に反映されます。

※ チャンネルIDは変えることができません。

※ 色コードなどの装飾が可能です。（colorよりもnameが優先されます）

※ 最大32文字まで入力できます。

#### 説明文 (description)
**チャンネルの説明文**を変えることができます。

ここで変更したものは`/ch list`や`/ch info`に反映されます。

※ 色コードなどの装飾は利用できません。

※ 最大128文字まで入力できます。

なお、`/ch set <チャンネルID> description`の後ろに何も入力せずに実行すると、説明文を削除できます。

#### フォーマット (format)
チャンネル内で送信されたチャットの見た目を変更できます。

以下の表にあるフォーマットを利用できます。

|フォーマット| 説明 | 備考 |
|---|---|---|
| %ch% | チャンネル名 ||
| %id% | チャンネルID ||
| %player% | 発言者の名前 | Minecraftで登録した名前 |
| %displayname% | 発言者の名前 | サーバー内での特殊な名前*1 |
|%msg%|本文||
|%title%|肩書き||
|%prefix%|`鯖主`などの名前の前につく要素|アチーブメントは対象外です|
|%suffix%|`(離席)`などの名前の後につく要素||
|%world%|ワールド名||
|%achievement_tag_short%|プレイヤーが設定しているアチーブメント||

*1：現時点でいねさばではそのような機能はありませんが、例えばニックネームなどを設定できるようになった場合はそのニックネームが使われるようになります。

※ `%player%` / `%displayname%` はどちらかが必須、`%msg%`は必須です。

なお、`/ch set <チャンネルID> format`の後ろに何も入力せずに実行すると、フォーマットはデフォルトに戻ります。

また、Minecraftの装飾コード (`&c`等) 及び一般的なHEXコード(`&#FFFFFF`等) 、太字 (`<bold>`) 、グラデーション (`<gradient:#FFFFFF:#000000>…</gradient>`) 、虹色 (`<rainbow>`) が利用できます。詳しくは以下の設定例を確認してください。

::::details{title="フォーマットの設定例"}
##### 例１

**表示例：** na9ruchan : こんにちは！

**設定フォーマット：** `%player% : %msg%`

##### 例２

**表示例：** <span style="color: #488A0F">なくるちゃん農園</span> na9ruchan <span style="color: #AAAAAA">:</span> こんにちは！

**設定フォーマット：** `&#488A0Fなくるちゃん農園 &r%player% &7: &r%msg%`

##### 例３

**表示例：** <span style="background: linear-gradient(90deg, #EBB06C, #FFAAA6); -webkit-background-clip: text; background-clip: text; color: transparent;">ねこかふぇ建築ch</span> 猫集め係 na9ruchan <span style="color: #AAAAAA"> (雑談歓迎) :</span> こんにちは！

**設定フォーマット：** `<gradient:#EBB06C:#FFAAA6>ねこかふぇ建築ch</gradient> &r%title% %player% %suffix% &7: &r%msg%`

##### 例４

**表示例：** <span style="color: #555555">[</span>雑談<span style="color: #555555">]</span> na9ruchan <span style="color: #AAAAAA">:</span> こんにちは！

**設定フォーマット：** `&8[&r%ch%&8] &r%player% &7: &r%msg%`

※ チャンネル名を変更した場合、自動的に新しいチャンネル名になります。

##### 例５
**表示例：** <span style="background: linear-gradient(90deg, #FF5555, #FFAA00, #FFFF55, #55FF55, #55FFFF, #5555FF, #FF55FF); -webkit-background-clip: text; background-clip: text; color: transparent; font-weight: bold;">夏祭り</span> na9ruchan <span style="color: #AAAAAA">:</span> こんにちは！

**設定フォーマット：** `<rainbow><bold>夏祭り</bold></rainbow> &r%player% &7: &r%msg%`

::::

#### 色 (color)
チャンネル名の色を変えられます。

TAB補完で出てくる色かHEXコード(#ffffffなど)を指定できます。

※ この項目のみHEXコードの前に`&`は不要です。

ここで変更した色は`/ch info`や`/ch list`のチャンネル名の色になります。

※ `name`で装飾をした場合そちらが優先されます。

#### パスワード (password)
チャンネルにパスワードを設定できます。

パスワードには1～32文字の空白以外の全ての文字を利用できます。

なお、`/ch set <チャンネルID> password`の後ろに何も入力せずに実行すると、パスワードを解除できます。

※ パスワードはPBKDF2（SHA-256）でハッシュ化して保存しています。ただし、サーバーのログには入力したコマンドがそのまま記録されるため、ログを閲覧できる運営（鯖主など）はパスワードを確認できる状態にあります。安全性は保証できませんので、ほかのサービスと同じパスワードは使わないでください。

※ 全角・半角の区別をします。全角「１,２,３,ア,Ａ,Ｂ,Ｃ」と半角「1,2,3,ｱ,A,B,C」など特に注意してください。

## 肩書きの設定
肩書きとはチャンネルの中だけで使える役職みたいなものです。

:command[/ch title <チャンネルID> <プレイヤー名> <肩書きの名前>]で設定ができます。

肩書きの名前には装飾コード及びHEXコードも利用可能です。

なお、`/ch title <チャンネルID> <プレイヤー名>`の後ろに何も入力せずに実行すると、肩書きを外せます。


# ダイレクトメッセージ
:command[/msg <プレイヤー名> <本文>]で`<プレイヤー名>`にメッセージを送信できます。

返信は:command[/r <本文>]で可能です。なお、返信を打っている途中で他ユーザーからDMが来た場合その人に送信されてしまいますのでご注意ください。

## ダイレクトメッセージ通知
デフォルトでは、放置時にダイレクトメッセージが来た場合に音が鳴ります。

通知の設定を変更したい場合は、:command[/menu]の一番下の列から「常に通知」・「通知オフ」・「放置時のみ通知」に変更可能です。

※ 音量はMinecraftの設定の「マスター音量」から変更可能です。

# その他の機能
- ローマ字の日本語化（Minecraftの設定言語が日本語の場合はデフォルト）
- 外国語の自動翻訳（DeepL翻訳。Minecraftの設定言語が英語の場合はデフォルト）
- URLをクリックで閲覧可能

※ ローマ字や外国語はいねさば独自の辞書を使っているため、一部翻訳が一般名と異なる場合があります。（いねさばの地名などに引っ張られる可能性があります）

# コマンド一覧

`[ ]` の部分は省略できます。チャンネルIDを省略した場合は、今の発言先が使われます。

## チャンネル

| コマンド | 説明 |
| --- | --- |
| :command[/ch] | ヘルプと今の発言先を表示 |
| :command[/ch list [ページ]] | チャンネル一覧（クリックで参加） |
| :command[/ch <チャンネルID>] | 発言先を切り替える（未参加なら参加する） |
| :command[/ch <チャンネルID> <本文>] | そのチャンネルに1回だけ発言する |
| :command[/ch join <チャンネルID> [パスワード]] | 参加して発言先にする |
| :command[/ch leave [チャンネルID]] | 退出する |
| :command[/ch who [チャンネルID]] | オンラインの参加者を表示 |
| :command[/ch info [チャンネルID]] | オーナー・説明・パスワードの有無などを表示 |
|:command[/ch local]|ローカルチャットに移動する|
|:command[/ch global]|グローバルチャットに移動する|
| `!<本文>` | 先頭に `!` を付けると、その発言だけグローバルチャットに送る |

## ダイレクトメッセージ

| コマンド | 説明 |
| --- | --- |
| :command[/msg <プレイヤー名> <本文>] | ダイレクトメッセージを送る（:command[/tell] :command[/w] :command[/whisper] も同じ） |
| :command[/r <本文>] | 最後にやり取りした相手に返信する（:command[/reply] も同じ） |

## ローマ字変換・言語

| コマンド | 説明 |
| --- | --- |
| :command[/ch romaji [on/kana/off]] | ローマ字変換（漢字まで / ひらがなだけ / しない） |
| :command[/ch lang [auto/ja/en]] | チャットの言語（auto はゲームの言語設定で決まる） |

## 自分のチャンネル（オーナー用）

| コマンド | 説明 |
| --- | --- |
| :command[/ch create <チャンネルID> [パスワード]] | チャンネルを作る（ID は英小文字・数字・`_`・`-`） |
| :command[/ch set <チャンネルID> <項目> [値]] | チャンネルの設定を変える（下の表） |
| :command[/ch title <チャンネルID> <プレイヤー名> [肩書き]] | 参加者に肩書きを付ける（省略すると外す） |
| :command[/ch kick <チャンネルID> <プレイヤー名>] | 参加者を追放する |
| :command[/ch owner <チャンネルID> <プレイヤー名>] | オーナーを参加者に譲る |
| :command[/ch delete <チャンネルID> [confirm]] | チャンネルを削除する |

### :command[/ch set] で変えられる項目

| 項目 | 説明 |
| --- | --- |
| `name` | 表示名（32文字まで・装飾できる） |
| `color` | 表示名の色（`red` などの色名か `#ff8800`） |
| `description` | 説明（128文字まで・省略で削除） |
| `password` | 参加パスワード（省略で解除） |
| `format` | チャットの見た目（省略で標準に戻す） |
