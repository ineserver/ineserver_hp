チェストやドアなどを保護する方法と使い方を解説します。

# 1. 自動保護

チェスト、かまど、ドア、看板などを設置すると、**自動的に保護（プライベート保護）がかかります。**

基本的には設置するだけで、自分以外のプレイヤーは開けられなくなります。

# 2. 保護のかけ方
## ① 保護の種類
保護には種類が5種類あります。
自分が使いたいタイプを選んで使ってください。

| コマンド | 説明 |
| --- | --- |
|:command[/lock private] |  自分だけが使える保護を作成します（通常はこれでOK）(/lockでも実行できます) |
|:command[/lock public] | 誰でも使うことはできますが、破壊することはできません (公共施設向け) |
|:command[/lock display] | 中身を見ることはできますが、アイテムを出し入れすることはできません |
|:command[/lock deposit] | アイテムを入れることはできますが、取り出すことはできません |
|:command[/lock  withdrawal] | アイテムを取り出すことはできますが、入れることはできません |

## ② 手動での保護のかけ方
保護のタイプを変更するとき・後で保護をかける時の手順です。
1. 保護のタイプを選び、コマンドを入力する (例: `/lock private` など)

2. 保護の対象(例: チェストなど)を左クリックする

これで、ブロックに保護をかけることができます。

# 3. メンバーの追加・削除（友達と共有する）

友達もチェストを開けられるようにしたい場合は、権限を変更します。

:::command
/bolt edit add [プレイヤー名]
:::

コマンド入力後、**共有したいブロックを左クリック**することで設定が反映されます。

もし、取り消したい場合は、

:::command
/bolt edit remove [プレイヤー名]
:::

で、取り消すことができます。

※コマンドを打った後に、対象のチェストを殴る（クリックする）のを忘れないでください。

また、**すべての保護**にアクセスできるようにするには、

:::command
/bolt trust add [プレイヤー名]
:::

で、すべての保護にアクセスできるようになります。

もし、取り消したい場合は、

:::command
/bolt trust remove [プレイヤー名]
:::

で、取り消すことができます。


# 4. 保護の削除

保護を解除して、誰でも開けられる状態に戻したい場合は以下のコマンドを使います。

:::command
/unlock
:::

コマンド入力後、**解除したいブロックを左クリック**してください。

# 5. 保護情報の確認

チェストやドアが現在どのような保護状態か確認するには、以下のコマンドを使います。

:::command
/bolt info
:::

コマンド入力後、対象を**左クリック**すると詳細が表示されます。

# 6. その他のコマンド

ブロック保護には、ほかにも便利な機能があります。

| コマンド | 説明 |
| :--- | :--- |
| :command[/bolt mode nolock] | 自動保護を無効化します |
| :command[/bolt mode nospam] | 保護をかけた時のメッセージの表示/非表示を切り替えます  |
| :command[/bolt mode persist] |  連続モード。一度コマンドを打つと、複数のブロックを連続してクリックで設定できます（解除は再度入力） |
| :command[/bolt password [パスワード]] | パスワード保護されたブロックを解錠します |
| :command[/bolt transfer [プレイヤー名]] | このコマンドを入力した後にブロックをクリックすることで、その保護の所有権を譲渡することができます |
| :command[/bolt help [サブコマンド]] | ブロック保護のヘルプをみることができます |

::::details{title="保護できる主なブロック"}
* チェスト / ラージチェスト / エンダーチェスト / トラップチェスト / 樽
* シュルカーボックス
* かまど / 溶鉱炉 / 燻製器
* ディスペンサー / ドロッパー
* ホッパー
* ドア / トラップドア / ゲート
* 看板/額縁
* 醸造台
* ジュークボックス
* 書見台
* 飾り壺

なお、錆止めのされていない銅系のドア・トラップドアはブロック保護の対象になりません。
::::
