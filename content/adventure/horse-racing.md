# 競馬の賭け方

![馬券販売機](https://img.1necat.net/2026-07-31_20.35.03.png)

馬券は100ineから購入することが可能です。

投票画面（I-PAG）は、:command[/ipag]で開くことが出来ます。

投票したい馬を**右クリックすることで単勝式**で、**2頭の馬をそれぞれ左クリックすることで馬連式**で馬券を買うことが出来ます。

* **単勝**：1着の馬を予想する
* **馬連**：1着と2着の馬を予想する（1着と2着の順番はどちらでも良い）

金額を選択し、購入完了となります。

（デフォルトの状態では100ineとなっています。+1000ineのボタンをクリックすると1100ine分投票されますので注意して下さい。）

## 馬券の販売期間・払戻について
馬券は「競走馬のエントリー終了」から「発走開始」まで購入可能です。

また、払戻はレース終了直後に自動的に行われます。

## 馬のステータスについて

**競走馬を「しゃがみ＋右クリック」する**ことで、ステータスを見ることが出来ます。

ここで閲覧できる情報は「馬名・馬主・性別・繁殖実績・血統」です。

また、投票画面では、「馬体重」も閲覧することが出来ます。

※ 馬体重は毎日変わります。投票の参考にする場合は注意して下さい。

### 見られないステータスについて
閲覧できませんが、内部的に競走馬が持っているステータスの一覧です。

#### 馬自体の基本ステータス
| 名称 | 説明 |
| :--- | :--- |
| 理想馬体重 | その馬が最もパフォーマンスを発揮できる体重 |
| 最高速度 | 馬の最大到達速度を決めるステータス |
| 加速度 | スピードの変化の滑らかさを決めるステータス |
| スタミナ | レース中に使われる体力。距離適性や脚質によって消耗速度が変わる。レース後は疲労度として蓄積される |
| 根性 | 他の馬と接近・並走した際に発揮される粘り強さ |
| 瞬発力 | レース終盤（残り30%）に発動するラストスパートの強さ（スタミナが残っている場合） |
| 馬場適性 | 得意な馬場（芝・ダート・万能） |
| 距離適性 | 得意な距離カテゴリ（短距離・マイル・中距離・長距離）。適性外の距離では余分なスタミナが消耗される |
| 脚質 | レース中の走り方のパターン（逃げ・先行・差し・追込）。序盤〜終盤それぞれのペース係数と、スタミナ消耗速度が異なる |

#### 馬のコンディション（毎日ランダム）
| 名称 | 説明 |
| :--- | :--- |
| 調子 | その日の馬の調子（絶好調・好調・普通・不調・絶不調）。全ステータスに対して乗算 |
| 疲労度 | レースや交配によって蓄積する疲労値 |

# 馬主になる

![パドック](https://img.1necat.net/2026-06-26_01.13.06.png)

馬主になって、自分の競争馬をレースに出すこともできます！

馬主になるためには **称号：[スキル：ゴールド]** が必要です。（McMMOパワーレベル2,000以上）

現在のパワーレベルは:command[/mcstats]をご利用ください。

（※レベルが2,000以上でも馬主のコマンドが使えない場合はお知らせ下さい）

## 馬をスポーンさせる
競走馬は通常の馬は利用できず、:command[/race spawn <馬名>]からのスポーンが必須です。

馬名は、1文字以上9文字以下の全角カタカナ（及び「ー」）を使用する必要があります。

なお、既に競走馬として登録されている名前は利用不可です。

馬は1プレイヤーにつき2体まで所有できます。（後に案内する交配で生まれた仔馬も含めた数字です）

また、**馬のスポーンには5,000ineがかかります。**

## 馬を競争にエントリーさせる
馬主は**自分の所有している競走馬に騎乗した状態で:command[/race entry <コース名>]を入力**するとレースにエントリーすることが出来ます。

エントリー後、運営によりエントリーが承認された場合、**エントリー料（10,000ine）を自動的に引き落としされます。**

※ 口座にエントリー料がない場合、エントリーは自動的に取消となります。

※ コース名や各競争の出場条件はDiscordにて公表致します。出場条件に合わない場合、エントリーが取消となります。→ https://discord.com/invite/tdefsEKYhp

※ エントリー承認後のエントリーの取り消しは、競争中止になった場合を除き、基本的に不可です。

## 馬を交配させる
牝馬と牡馬を交配させ、新たな仔馬を誕生させることも可能です。

**競走馬を「しゃがみ＋右クリック」する**ことで、馬の性別を確認することが出来ます。

:command[/race breed <父馬名> <母馬名> <仔馬名>]で交配が可能です。

コマンドを入力すると相手馬主に確認のメッセージが流れます。承認する場合は:command[/race breedaccept]、否認する場合は:command[/race breeddeny]を入力して下さい。

30秒以内にどちらかのコマンドを入力しない場合、自動的に否認となります。

※ 馬名及び馬の数はスポーンと同条件です。

※ **馬の交配には10,000ineがかかります。**（/race breedコマンドを打った側に請求されます）

※ 交配時、最大1.05倍の全体的なステータス上昇があります。なお15%の確率で失敗（ステータスの大幅ダウン）があります。

※ 交配は馬につき生涯で3回まで可能です。また、同じ馬が交配が可能になるまで1周間のクールダウンがあります。

## 馬の引退
自分の所有する馬のうち、:command[/race release <馬名>]を入力すると該当する馬は引退し、自らの所有競走馬の数が一つ空きます。

該当競走馬は、コマンドを打った時点でマイクラの普通の馬と同じMOBとなり、攻撃なども通るようになります。

※ 馬を引退させた後15分間は新しく馬をスポーンさせることができなくなります。

# システムについて
いねさばの競馬では、以下のようなシステムを採用しています。

- 控除率：10%
- オッズが1.0倍未満になる場合は1.0倍で固定
- 馬主への賞金は、控除率のうち80%を次のように分配。1着：60%、2着：25%、3着：15%。
（例：馬券売上 10,000 ine の場合→馬主賞金は1着は480ine、2着は200ine、3着は120ine）
- 馬主のエントリー料は90%が賞金プールに入り、次のように分配。1着：60%、2着：25%、3着：15%。
（例：エントリー料合計 15,000 ineの場合→馬主賞金は1着: 8,100 ine、2着: 3,375 ine、3着: 2,025 ine）
- 馬主への賞金は上記の控除金の8割＋エントリー料賞金プールの合計から分配となる
- 何らかの事象で競争が中止になった場合は全額払い戻しとなる
- 同着の場合、払戻は、同着によって増えた的中パターンの数で、払戻プール金を均等に分割し、賞金は、該当する着順枠の規定賞金を、同着となった頭数で均等に山分けする。

（ちなみに、I-PAGは、Ine Personal Access Guiの略です）
