# 競馬の賭け方

![馬券販売機](https://img.1necat.net/2026-07-31_20.35.03.png)

馬券は100ineから購入することが可能です。

投票画面（I-PAG）は、:command[/ipag]で開くことが出来ます。

* **単勝**：1着の馬を予想する
* **馬連**：1着と2着の馬を予想する（1着と2着の順番はどちらでも良い）

## 馬券の買い方
1. :command[/ipag]で投票画面を開きます。複数のレースを発売しているときは、矢印のボタンでレースを切り替えられます。
2. 買い方を選びます。
   * **単勝**：投票したい馬を**左クリック**します。
   * **馬連**：2頭の馬をそれぞれ**右クリック**して選び、「馬連を決定」をクリックします。
3. 金額のボタン（+100ine〜+10,000ine）で金額を決め、「購入確定」をクリックすると購入完了です。

（最初は100ineになっています。+1,000ineのボタンをクリックすると1,100ine分投票されますので注意して下さい。金額は「リセット」で0ineに戻せます。）

買った馬券は、投票画面の「所有馬券一覧」か:command[/keiba tickets]で確認できます。

## 馬券の販売期間・払戻について
馬券は「競走馬のエントリー締切」から「発走」まで購入可能です。

払戻はレース確定直後に自動的に行われます。

出走を取り消した馬（除外）がいる場合、その馬の単勝と、その馬を含む馬連は返還されます。

## 予想の手がかり

投票画面では、それぞれの馬の **「馬主・性齢（例：牡3）・クラス・特技・馬体重・単勝オッズ」** を見ることが出来ます。

また、**競走馬を「しゃがみ＋右クリック」する**と、「馬名・馬主・年齢・クラス・成績・性別・血統・繁殖実績」を見ることが出来ます。近くの馬の情報は:command[/keiba info]でも確認できます。

過去の成績や馬柱は[競馬情報ページ](/keiba)で確認できます。

※ 馬体重は毎日変わります。投票の参考にする場合は注意して下さい。

※ 能力の数値・適性・脚質・調子は、公正なレースのため公開していません。パドックでの馬の様子が手がかりになるかも・・・？

### 馬の能力
| 名称 | 説明 |
| :--- | :--- |
| 理想馬体重 | その馬が最もパフォーマンスを発揮できる体重 |
| 最高速度 | 馬の最大到達速度を決める能力 |
| 加速 | スピードの上がりやすさを決める能力 |
| スタミナ | レース中に使われる体力。距離適性や脚質によって減り方が変わる |
| 根性 | 他の馬と接近・並走した際に発揮される粘り強さ |
| 瞬発力 | レース終盤のラストスパートの強さ（スタミナが残っている場合） |
| 馬場適性 | 得意な馬場（芝・ダート・万能） |
| 距離適性 | 得意な距離（ダッシュ・スプリント・ミドル・ロング）。合わない距離ではスタミナを余分に使う |
| 脚質 | レース中の走り方（逃げ・先行・差し・追込）。序盤〜終盤のペース配分とスタミナの減り方が異なる |

※ 能力の数値は公開していません。馬主は、自分の馬の能力を G〜S の段階で見ることが出来ます。

### 馬のコンディション
| 名称 | 説明 |
| :--- | :--- |
| 調子 | その日の馬の調子（絶好調・好調・普通・不調・絶不調）。毎日変わる |
| 疲労 | レースや調教で溜まり、日がたつと少しずつ回復する |
| 愛情度 | 馬主が餌をあげると上がる（1日1回まで）。餌をあげない日が続くと下がる |
| 馬体重 | 毎日変わる。馬主が特別な餌で増やしたり減らしたりできる（1日1回まで） |

※ 調子は誰にも見えません。疲労と愛情度は、馬主だけが自分の馬について見られます。

### 特技
育成や調教で「ひらめき」を得ると、馬が特技を身につけることがあります（1頭3つまで）。特技は投票画面にも表示されます。

| 特技 | 効果 |
| :--- | :--- |
| スタート上手 | 出遅れない |
| 内ラチ巧者 | 前が詰まっても、少しだけ速く走れる |
| 末脚 | ラストスパートがよく伸びる |
| ペース巧者 | レースのペースの影響を受けにくい |
| 根性勝負 | 他の馬が近くにいるときによく伸びる |
| スタミナ温存 | スタミナが減りにくい |

- :command[/keiba odds]：オッズを確認する
- :command[/keiba tickets]：自分の購入した馬券を確認する
- :command[/keiba info]：近くの馬の情報を確認する

# 馬主になる

![パドック](https://img.1necat.net/2026-06-26_01.13.06.png)

馬主になって、自分の競走馬をレースに出すこともできます！

馬主になるためには **称号：[スキル：ゴールド]** が必要です。（McMMOパワーレベル2,000以上）

現在のパワーレベルは:command[/mcstats]をご利用ください。

（※レベルが2,000以上でも馬主のコマンドが使えない場合はお知らせ下さい）

## 馬主画面
馬主の操作は、ほとんど **馬主画面** からできます。馬主画面は、以下のコマンドで開きます。

:::command
/keiba
:::

馬主画面では、次のことが出来ます。

* 自分の馬の一覧（競走馬・子馬・牧場の馬）と、馬ごとの詳しい情報
* 子馬を買う・育成する・競走馬に登録する
* レースへの申請と取消
* 調教と、調教に使う飼い葉を預ける
* 引退・牧場・配合・譲る・手放す
* 今のシーズンと、今週の調教一番時計

馬ごとの画面では、「年齢・クラス・成績・能力の段階・愛情度・馬体重・疲労・特技・因子・分かっている適性・調教の自己ベスト」を見ることが出来ます。

## 馬の一生
馬は **子馬 → 競走馬 → 牧場** の順に進みます。

| 段階 | 年齢 | できること |
| :--- | :--- | :--- |
| 子馬 | 1歳 | 育成。レースや配合はできません（マイクラの子馬の姿です） |
| 競走馬 | 2歳〜 | レース・調教・餌やり |
| 牧場の馬 | — | 配合・見物 |

### シーズンと年齢
いねさばの競馬は、**半年で1シーズン** です。シーズンが変わると、競走馬と牧場の馬が1つ年をとります。

競走馬に登録した馬は、そのシーズンの「デビュー世代」の2歳になります。主に2歳と3歳の馬が走り、4歳以降も走ることが出来ますが、年をとるとやがて衰えていきます。

馬ごとに成長の早い・遅い（成長型）があり、強さのピークになる年齢が違います。成長型は誰にも公開されないので、走った結果から読み取ってみて下さい。

## 持てる馬の数
| 種類 | 1人あたりの上限 |
| :--- | :--- |
| 競走馬 | 2頭 |
| 子馬 | 2頭（競走馬とは別に数えます） |
| 牧場の馬 | McMMOの調教（Taming）のレベルで決まります（下の表） |

| Tamingのレベル | 牧場に置ける頭数 |
| :--- | :--- |
| 0〜99 | 1頭 |
| 100〜 | 2頭 |
| 250〜 | 3頭 |
| 500〜 | 4頭 |
| 1,000〜 | 5頭 |

## 子馬を手に入れる
子馬は、**購入** するか **配合** で生まれます。

購入は、馬主画面の「子馬を買う」か、:command[/keiba spawn <馬名>]で出来ます。**子馬の購入には5,000ineがかかります。**

馬名は、1文字以上9文字以下の全角カタカナ（及び「ー」）を使用する必要があります。

なお、既に登録されている名前は利用不可です。

※ 馬を手放した後15分間は、新しく子馬を手に入れることができません。

## 子馬を育成する
子馬は、馬主画面から **24ターンの育成** をして能力を伸ばします。育成は1頭につき1回です。

1ターンに1つメニューを選ぶと、すぐに結果が出ます。

| メニュー | 主に伸びる能力 |
| :--- | :--- |
| スピード | 最高速度 |
| 加速 | 加速 |
| スタミナ | スタミナ |
| 根性 | 根性 |
| 瞬発力 | 瞬発力 |
| 休養 | 体力が戻る |

* **体力**：トレーニングで減り、休養で戻ります。体力が少ないと失敗しやすくなり、失敗すると能力が伸びず、調子が下がります。
* **調子**：調子がいいほど、よく伸びます。
* **出来事**：育成中には「好時計」「気合い十分」「脚元の不安」などの出来事が起きます。脚元に不安があるまま鍛えると、故障することがあります。
* **模擬レース**：育成中に2回まで、子馬が実際にコースを走る模擬レースに出られます（1ターン使います）。着順がいいほど能力が伸びます。子馬の近くで始めてください（レースが行われる日は走れません）。

馬ごとに伸びる上限（素質）があり、上限に近いほど伸びにくくなります。

育成は途中で保存されるので、ログアウトしても続きから遊べます。育成をするとMcMMOのTamingの経験値ももらえます。

24ターンが終わると、能力から **評価ランク（S〜E）** が付き、育成の結果がその馬の能力になります。最後に、次のどれかを選びます。

* **競走馬に登録する**：2歳の競走馬になり、レースに出られるようになります（クラスは未勝利から）。
* **牧場に置く**：配合に使えます。
* **手放す**

### 因子
育成を終えると、特に良かった2つの能力に「因子（★1〜3）」が付きます。因子を持つ馬から生まれた子馬は、その能力が少し高い状態から育成を始められます。

## 馬をレースに申請する
馬主画面で競走馬を選び、**「レースに申請する」** から申請できます。受付中のレースが並び、申請できないレースには理由が表示されます。

レースを選んだら、レース後の戻し先を選びます。

* **元の場所に戻す**：レース後、申請したときに馬がいた場所に戻ります。
* **引き上げ所に置く**：レース後、引き上げ所（厩舎の南側）に移動します。

※ 馬に乗っていなくても申請できますが、馬の近く（馬が読み込まれているところ）で申請して下さい。

※ 馬に乗った状態で:command[/keiba entry <レース名> <back|pickup>]を入力しても申請できます。（back：元の場所に戻す、pickup：引き上げ所に置く）

申請すると、馬はすぐにパドックへ移動します。

**エントリー料（10,000ine）** は、自動承認のレースでは申請したとき、運営が承認するレースでは承認されたときに引き落とされます。

※ エントリー料が足りない場合は申請できません。運営が承認するレースで、承認のときに足りない場合は申請が取消になります。

※ 1つのレースに申請できるのは、1人2頭までです。

※ レース名や各競争の出場条件は[i-keiba](/keiba)にて公表致します。:command[/keiba races]でも確認できます。

### 申請の取消
エントリーの締切前であれば、馬主画面の「申請を取り消す」か:command[/keiba cancel <レース名>]で取り消せます。エントリー料は返金されます。

（同じレースに2頭申請している場合は、:command[/keiba cancel <レース名> <馬名>]で馬を指定して下さい。）

締切後の取り消しは、競争中止になった場合を除き、基本的に不可です。

### 申請中の馬
申請してからレース後に戻るまでの間、その馬に乗る・リードをつける・インベントリを開く・譲る・手放すことはできません。（餌はあげられます）

## 調教する
競走馬は、馬主画面の「調教する」から、**1日1回** 調教が出来ます。

1. 鍛える能力（スピード・加速・スタミナ・根性・瞬発力）を選びます。
2. 強さ（**馬なり・強め・一杯**）を選びます。強いほどよく伸びますが、疲労が溜まり、故障しやすくなります。
3. 走るコースを選ぶと、馬がコースを1頭で走り、タイム（走破タイム・上がり・ラップ）が計られます。走り終わると、馬は元の場所に戻ります。

* 調教には **飼い葉** を使います。馬主画面の「飼い葉を預ける」から、手持ちの飼い葉を厩舎に預けておいて下さい（預けられるアイテムはボタンの説明に表示されます）。強さによって使う数が変わります。
* 馬の近く（馬が読み込まれているところ）で始めて下さい。
* レースが行われる日は、どのコースでも調教できません。
* 故障すると、数日間は調教もレースもできなくなります。
* しばらく調教もレースもしないと、鍛えた分が少しずつ落ちていきます（育成を終えたときの能力より下がることはありません）。

調教のタイムは、馬ごとの自己ベストとして記録されます。コースごとの「今週の調教一番時計」は、馬主画面や競馬場の掲示板で見ることが出来ます。

### 適性が分かる
レース・調教・模擬レースで何度か走ると、その馬の **芝・ダートの向き不向き、距離の向き不向き、脚質** が馬主に分かってきます。分かった適性は馬主画面で確認できます。

## 馬に餌を与える
餌は厩舎の北側の村人で交換できます。

必要なアイテムは変わる可能性があります。

餌は、餌を持って馬を右クリックすると与えられます。自分の馬にだけ与えられます。

### 飼い葉（愛情度の餌）
1日1回まで「飼い葉」を与えることができます。

愛情度が上がると、馬の走りが少し良くなります。餌をあげない日が続くと、愛情度は下がっていきます。

### 米ぬか飼料（体重を上げる餌）
「米ぬか飼料」と「稲わら飼料」をあわせて1日に1つまで与えることができます。

米ぬか飼料では1.5kg、体重を上げる事ができます。

なお上げすぎるとそれ以上に上がらなくなりますので注意して下さい。

### 稲わら飼料（体重を下げる餌）
「米ぬか飼料」と「稲わら飼料」をあわせて1日に1つまで与えることができます。

稲わら飼料では1.5kg、体重を下げる事ができます。

なお下げすぎるとそれ未満に下がらなくなりますので注意して下さい。

※ 体重の餌は、エントリーの締切からレースが終わるまでの間は与えられません。

## 引退と牧場
競走馬は、馬主画面の「引退して牧場へ」からいつでも引退させられます（申請中は不可）。引退した馬は牧場に置かれ、配合に使えるようになります。

### 牧場
牧場の馬は、ワールドに馬として置かれ、誰でも見に行くことが出来ます。名札には馬名と成績が表示されます。（馬主以外は、乗る・リードをつける・攻撃する・餌をあげることはできません）

牧場には、**自分の牧場** と、運営が用意した **公開の牧場**（誰の馬でも置ける）があります。どの牧場に置くかは、馬主画面で選べます。

自分の牧場は、馬主画面の「牧場」→「牧場を作る」か、:command[/keiba farm set <名前> [広さ]]で作れます。

* 今いる場所を中心に作られます。自分の土地に作って下さい。
* 1人2か所まで、広さは一辺40ブロックまでです。
* 自分の牧場には、自分の馬だけを置けます。
* 馬がいる牧場は消せません。

:command[/keiba farm list]で牧場の一覧、:command[/keiba farm remove <名前>]で自分の牧場を消せます。

## 馬を配合させる
**牧場にいる** 牡馬と牝馬を配合させ、新たな子馬を誕生させることが出来ます。（競走馬や子馬は配合できません）

馬主画面の「配合」から、父馬 → 母馬 → 子馬の名前の順に選びます。:command[/keiba breed <父馬名> <母馬名> <子馬名>]でも配合できます。

子馬は、両親の素質を受け継いで生まれます。ただし、まれに配合がうまくいかず、素質が下がってしまうこともあります。（育成や調教で伸ばした分は受け継がれません）

### 他の馬主の馬との配合
他の馬主の馬と配合する場合は、その馬主の承認が必要です。（両親とも別の人の馬なら、2人とも承認が必要です）

* 相手の馬主がオンラインのときだけ申し込めます。
* 申し込みは10分で消えます。申し込みは1人1件までです。
* 届いた申し込みは、馬主画面の「配合の申し込み」で承認・断ることが出来ます。自分の申し込みの取り下げもここで出来ます。
* :command[/keiba breedaccept]（承認）・:command[/keiba breeddeny]（断る）でも、届いた中でいちばん古い申し込みに答えられます。
* 子馬は申し込んだ人のところに生まれるので、承認されるときに申し込んだ人がオンラインである必要があります。

※ 種付け料など、馬主どうしのお金のやり取りは、当事者どうしで決めて下さい。

※ 子馬の名前と持てる数は、購入と同じ条件です。

※ **馬の配合には10,000ineがかかります。**（配合を申し込んだ側に請求されます）

※ 配合は馬につき生涯で3回までです。また、同じ馬が再び配合できるまで1週間のクールダウンがあります。

## 馬を譲る・手放す
### 譲る
馬主画面の「譲る」から、オンラインの馬主に馬を譲ることが出来ます。:command[/keiba setowner <プレイヤー名> <馬名>]でも譲れます。

※ 相手が持てる馬の数に空きがないと譲れません。

※ 自分の牧場にいる馬は、公開の牧場へ移してから譲って下さい。

### 手放す
馬主画面の「手放す」か:command[/keiba release <馬名>]で、馬を手放すことが出来ます。手放した馬は消え、**元に戻すことはできません**。

※ 馬を手放した後15分間は、新しく子馬を手に入れることができなくなります。

# システム
いねさばの競馬では、以下のようなシステムを採用しています。

- 控除率：10%
- オッズが1.0倍未満になる場合は1.0倍で固定
- 馬主への賞金は、控除率のうち80%を次のように分配。1着：60%、2着：25%、3着：15%。
（例：馬券売上 10,000 ine の場合→馬主賞金は1着は480ine、2着は200ine、3着は120ine）
- 馬主のエントリー料は90%が賞金プールに入り、次のように分配。1着：60%、2着：25%、3着：15%。
（例：エントリー料合計 15,000 ineの場合→馬主賞金は1着: 8,100 ine、2着: 3,375 ine、3着: 2,025 ine）
- 馬主への賞金は上記の控除金の8割＋エントリー料賞金プールの合計から分配となる
- 何らかの事象で競争が中止になった場合は全額払い戻しとなる
- 同着の場合、払戻は、同着によって増えた的中パターンの数で、払戻プール金を均等に分割し、賞金は、該当する着順枠の規定賞金を、同着となった頭数で均等に山分けする。

（ちなみに、I-PAGは、Ine Personal Access Guiの略です）

# レース
基本的には

新馬・未勝利 → 1勝クラス → OP → G2 → G1

の順番で出場できます。（各クラスのレースで優勝した場合次のクラスにいけます）

デビュー前の馬や、まだ1勝もしていない馬は「新馬・未勝利」クラスです。

なお、1勝クラスで優勝した場合、**OP馬**となり、OP・G2・G1に参加できるようになります。

ただし、「格上挑戦」ができるレースでは、下のクラスの馬も出場できます。

## 年齢限定のレース
レースによっては、「2歳限定」「3歳限定」「3歳以上」のように、出場できる年齢が決まっている場合があります。

## 出場馬の選び方
レースによっては定員があり、「先着順」か「賞金の多い順」で出場馬が決まります。また、ファン投票などで運営が出場馬を選ぶレースもあります。

詳しくは、各レースの出場条件を[i-keiba](/keiba)でご確認下さい。

## レースの距離
馬ごとに適正距離があります。

いねさばの案内等で利用されている距離とその呼び方は以下のとおりです。

- 0m ～ 900m ：DASH（ダッシュ / 超短距離）
- 900m ～ 1200m ：SPRINT（スプリント / 短距離）
- 1200m ～ 1400m ：MIDDLE（ミドル / 中距離）
- 1400m ～ 無制限 ：LONG（ロング / 長距離）

## レースのペース
レースごとに流れ（ペース）があり、速い流れになるか、ゆったりした流れになるかで、脚質による有利・不利が変わります。

# 特別賞金
馬券売上＋馬主エントリー料金＝通常賞金（プール）に追加して、運営から特別賞金が送られます。

以下はデフォルトの特別賞金です。

※ 一部のレースではこの賞金にならないことがあります。

| クラス | 特別賞金合計額(ine) | 1着 | 2着 | 3着 |
| --- | --- | --- | --- | --- |
| 新馬・未勝利 | 10,000 | 6,000 | 2,500 | 1,500 |
| 1勝 | 15,000 | 9,000 | 3,750 | 2,250 |
| OP | 30,000 | 18,000 | 7,500 | 4,500 |
| G2 | 60,000 | 36,000 | 15,000 | 9,000 |
| G1 | 120,000 | 72,000 | 30,000 | 18,000 |

※ それぞれのクラスで1着になった場合の最低賞金は以下の通りです。（4頭立て）

- 新馬・未勝利：27,600ine + 馬券売上
- 1勝：30,600ine + 馬券売上
- OP：39,600ine + 馬券売上
- G2：57,600ine + 馬券売上
- G1：93,600ine + 馬券売上
