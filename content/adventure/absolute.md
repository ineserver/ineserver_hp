「**アブソリュート**」とは、 **生まれた時に決まる「素質」** と、 **どこで何を掘ってきたかの「履歴」** によって、 **1本ずつ違う風に育つ道具** です。

普段どおり使っているだけで、あなたの使い方に合わせて自動で育ちます！

# 1. 対象の道具

- ツルハシ
- 斧
- シャベル
- クワ
- ハサミ
- 釣り竿

アブソリュートは、名前の先頭に「**\***」が付いています（例：\*ダイヤモンドのツルハシ）。

説明文の1行目に「アブソリュート」と書かれているのが目印です。

# 2. 入手方法

## 鍛冶屋にクラフトしてもらう

アブソリュートの素体（レベル0の状態）は、**職業「鍛冶屋」に就いている人だけ**が作業台でクラフトできます。

作り方は普通の道具とほぼ同じで、**棒の部分をブレイズロッドにする**だけです。

| 道具 | レシピ |
| --- | --- |
| ツルハシ・斧・シャベル・クワ | 普通のレシピの棒をブレイズロッドにする |
| 釣り竿 | 普通のレシピの棒をブレイズロッドにする（糸はそのまま） |
| ハサミ | 鉄インゴット2つ（斜め）＋ 空いているマスにブレイズロッド1本 |

素材は木・石・銅・鉄・金・ダイヤモンドが使えます。ネザライトは、ダイヤモンドのアブソリュートを鍛冶台で強化してください（育ち具合はそのまま引き継がれます）。

ロッドを**すべてブリーズロッド**にすると、いい素質が出るようになります！

※ 素質はクラフト画面から取り出した瞬間に決まります。シフトクリックや数字キーでは取り出せないので、何も持っていない状態で1本ずつクリックして取り出してください。

鍛冶屋以外の方は、鍛冶屋さんに作ってもらったり、買ったりしましょう！

## はじめてクエストの報酬

1本目は「はじめてクエスト」の報酬としてもらえます（素質はランダムです）。

# 3. 素質

素体が生まれた時に、5段階の「**素質**」が1つ決まります。素質は強弱記号で呼ばれ、説明文に「素質 p（ピアノ）」のように表示されます。

| 素質 | 読み | ブレイズロッドでの出現率 | ブリーズロッドでの出現率 |
| --- | --- | --- |
| p | ピアノ | 40% | 0% |
| mp | メゾピアノ | 30% | 15% |
| mf | メゾフォルテ | 20% | 45% |
| f | フォルテ | 10% | 25% |
| ff | フォルティッシモ | 0% | 15% |

※ 出現率はブレイズロッドで作った場合です。

素質が高いほど、**スキルを覚えやすく**なります。<span class="text-red">**ffが大当たり**</span>です！

素質は採掘速度などには影響しません。また、道具の名前の色も素質に合わせた色になります。

# 4. 育て方

## 経験値

道具を使うと経験値が貯まり、レベルが上がります。

経験値は道具そのものに貯まるので、育てた道具はそのまま人に渡したり、売り買いしたりできます。

| 道具 | 経験値が入る行動 |
| --- | --- |
| ツルハシ・シャベル | 自然のブロックを掘る（1ブロックで1） |
| 斧 | 原木を切る（1つで2）<br>※ 武器として使っても育ちません |
| クワ | 実った作物を収穫する（1つで1）<br>※ 稲も対象です |
| ハサミ | 羊などの毛刈り（1回で3）<br>葉や草などの植物を刈る（1ブロックで1）<br>蜂の巣から巣板を採る（1回で5） |
| 釣り竿 | 釣り上げる（1回で20）<br>※ 放置釣りでは育ちません |

斧で板材や竹を切った時、クワで葉などを壊した時も、少しだけ経験値が入ります。

- 自分や他の人が**置いたブロック**、**丸石・玄武岩製造機**で生成されたブロック、骨粉で生やした草などでは経験値は入りません。
- Jobsの職業に関係なく、誰でも育てられます。
- 釣り竿は、mcMMOで「魚が少なくなってきた」と表示される状態（同じ場所で釣り続けている状態）では経験値が入りません。少し場所を変えて釣りましょう。

## レベル

最大レベルは**300**（ハサミは**100**）です。最大レベルに達すると「**完成体**」になります。

## 履歴

説明文には、その道具で何をどれだけ掘ってきたかの「**履歴**」が、色付きのバーで表示されます（例：深層 41%／石 30%／ネザー 18%／建材 11%）。

::::details{title="履歴の分類の一覧"}

| 道具 | 分類 |
| --- | --- |
| ツルハシ | **石**（石・丸石・安山岩・閃緑岩・花崗岩、普通の鉱石）<br>**深層**（深層岩・凝灰岩、深層の鉱石）<br>**ネザー**（ネザーラック・玄武岩・ブラックストーン、ネザーの鉱石・古代の残骸）<br>**建材**（砂岩・テラコッタ・氷・エンドストーンなど） |
| 斧 | **温帯の木**（オーク・シラカバ・ダークオーク・ペールオーク）<br>**大木**（トウヒ・ジャングル）<br>**暖地の木**（アカシア・マングローブ・サクラ）<br>**ネザーの茎**（真紅の幹・歪んだ幹） |
| シャベル | **土**（土・草ブロック・ポドゾル・泥など）<br>**砂**（砂・赤い砂・怪しい砂）<br>**砂利と粘土**（砂利・怪しい砂利・粘土）<br>**雪とソウルサンド**（雪ブロック・粉雪・ソウルサンド・ソウルソイル） |
| クワ | **穀物**（小麦・稲）<br>**根菜**（ニンジン・ジャガイモ・ビートルート）<br>**ウリ**（スイカ・カボチャ）<br>**ネザーウォート** |
| ハサミ | **羊毛**（羊・ムーシュルーム・スノーゴーレムの毛刈り）<br>**植物**（葉・ツタ・クモの巣・草など、巣板の採取） |
| 釣り竿 | **海**・**川**・**沼地**（浮きが落ちた場所のバイオーム） |

どの分類にも入らないもの（黒曜石やアメジストなど、海・川・沼地以外の水辺）は、経験値だけ入って履歴には入りません。

## 癖

25レベルごとに、**その25レベルの間で一番多く掘った分類**の「**癖**」が1つ付きます（Lv300までに12個、ハサミはLv100までに4個）。

| 癖 | 効果（1つあたり） | 上限 | 付く道具 |
| --- | --- | --- | --- |
| 速さ | その分類のブロックの採掘速度 +6% | +60% | ツルハシ・斧・シャベル |
| 丈夫さ | その分類で使った時に、耐久が減らない確率 +5% | 50% | すべて |
| 伸び | その分類で得る経験値 +8% | +80% | すべて |

同じ分類・同じ種類の癖は重なり、説明文には「深層・速さ ×3」のようにまとめて表示されます。

どの種類の癖が付くかはランダムですが、**どの分類に付くかは掘り方次第**です。深層を掘り続ければ深層の癖が、ネザーを掘り続ければネザーの癖が付きます。

# 5. スキル

レベルが上がった時に、まれに「**スキル**」を覚えることがあります。

- 素質が高いほど覚えやすくなります。
- 最近よく掘っている分類にちなんだスキルを覚えやすくなります。
- 持っているスキルが多いほど、次を覚えにくくなります。だいたい2つ前後で、3つ目は大当たりです。
- 覚えたスキルは外せません。
- スキルは**実際に働いた回数**で深まり、効果が強くなります（説明文の ●○○ が段階です）。

**どんなスキルがあるかは公開していません。** 自分の道具に付いたものだけが説明文に表示されます。

掘る時に気配を音で知らせてくれたり、うっかり壊したくないものを壊さずに済んだりと、作業を少し快適にしてくれるものが中心です。どんなスキルを覚えるかは、育ててからのお楽しみ！

# 6. 名前・耐久・修理

## 名前を変える

金床で好きな名前に変えられます。先頭の「\*」は自動で付き直します。

## 耐久

- 耐久が尽きても**壊れません**。耐久1で止まり、修理するまで使えなくなります（説明文に表示されます）。
- 修理は金床など、普段どおりの方法でできます。
- 金床の「累積コスト」は毎回リセットされるので、何度修理しても高くなりすぎません。

## エンチャント

エンチャントは普通の道具と同じように付けられますが、<span class="text-red">**修繕だけは付けられません**</span>。

※ 大事な道具を消してしまわないよう、育ったアブソリュートは金床の右側（素材側）に置けません。また、作業台や砥石で2本を合わせることもできません。

# 7. ダ・カーポ（D.C.）と継承

完成体になったアブソリュートは「**ダ・カーポ（引退）**」させることができます。

ダ・カーポ（D.C.）をすることで、完成体を素体からやり直させ、癖かスキルを1つだけ次の1本へ持ち越せます。

1. 完成体を手に持って、:command[/absolute dacapo] を入力します。
2. 画面にその道具の癖とスキルが並ぶので、次の道具に持ち越したいものを**1つ**選びます。
3. 確認画面で「ダ・カーポする」をクリックすると、道具は無くなり、選んだものが「**継承の譜**」として手元に残ります。

※ スキンは継承できません

## 継承の譜の使い方

金床の左に**同じ種類の**アブソリュート、右に継承の譜を置くと引き継げます（経験値レベルを5消費します）。

- 引き継げるのは、癖×1かスキル1つです（スキルは深まった段階のまま引き継がれます）。
- 引き継いだものは、癖の上限・スキルの数とは**別枠**になり、説明文に「**D.C.**」の印が付きます。
- 1本の道具に引き継げるのは1つまでです。
- すでに覚えているスキルは引き継げません。
- 経験値と素質は引き継がれません。

# 8. スキン
一部のイベントなどでアブソリュート専用スキンを入手することができます。

スキンは使い捨てで、継承などは一切不可です。

アブソリュートにスキンを適用する場合、スキン適用アイテムをアブソリュートにドラッグ＆ドロップしてください。
