# この更新作業は終了致しました！
ご協力ありがとうございました！！！！

# はじめに
1.21以降、マインクラフトはテクスチャの構成等をバージョンを追う毎に大幅に変えてきました。

そのため、いねさばでは自動でテクスチャ構成をしてくれるプラグインへの移行を順次行っています。

その一環として、現在サーバー内に存在するアイテムにおいて、表示が乱れてしまう可能性がございます。

表示が乱れてしまった場合の応急処置方法などは以下をご確認下さい。

# 操作日時
2026年6月23日から順次行っております。終了時期は未定です。

# 影響範囲
いねさばにアクセス可能な全てのバージョンにて、特に追加防具（サーバー独自のアイテム）にて「読み込みエラーブロック（紫と黒色の表示）」になる可能性がございます。

# 応急処置
プレイに支障がある場合は、テクスチャを一旦抜いていただくと元の防具の見た目になりますのでそちらをお試しください。

なお、テクスチャを抜いても防具の性能自体は変わりません。

※ テクスチャはサーバー選択画面→いねさばを選択→下の「編集」→「サーバーリソースパック：有効」をクリックして「サーバーリソースパック：無効」にすると抜いた状態でサーバーにログインすることが出来るようになります。

# 移行完了後について
移行完了後、該当プラグインで生成されたテクスチャを配布致します。

なお、テクスチャのダウンロード以外でユーザーの皆さまが特殊な操作をする必要はございません。

（アイテムの交換などなく、移行できるように現在進めております）
