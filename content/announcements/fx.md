12月4日（金）までの期間限定で、[職業](/life/jobs)で貯めた **職業ポイント** を使って遊ぶ「**FX**」をお試し開催します！

銘柄の値がこれから上がるか下がるかを予想して取引を始め（**建て**）、好きなときに終わらせる（**決済**）と、その間の値動きに応じて職業ポイントが増えたり減ったりします。

<span class="text-red">**失うのは、多くても「証拠金」と「手数料」までです。**</span> それ以上のポイントが引かれることはありません。

※ 銘柄には職業の名前を借りていますが、値はサーバーが作り出しているもので、[アイテム市場](/economy/market)の価格や職業そのものとは関係ありません。住民が売り買いしても値は動きません。

※ このページの数値（倍率・枚数・上限・手数料など）は変更されることがあります。ゲーム内の画面に表示されている数値が正しい値です。

# 1. 開催期間

2026年11月21日（土） ～ <span class="text-red">**2026年12月4日（金）**</span>

期間が終わると、残っている建玉はその時点の値で自動的に決済されます。取引の期間は、:command[/fx] のメインメニューでも確認できます。

# 2. かんたんな遊び方

1. :command[/fx] でメインメニューを開きます。
2. 銘柄（農家・鉱夫・冒険家）をクリックします。
3. 左下のブロックで「買い」か「売り」を選び、右の枠をクリックすると建ちます。
4. やめたいときは、メインメニューで自分の建玉をクリックして決済します（2回クリック）。

# 3. 用語

| 用語 | 意味 |
| :--- | :--- |
| **建てる／建玉（たてぎょく）** | 取引を始めること／今持っている取引 |
| **買い** | 値が**上がると**得をする |
| **売り** | 値が**下がると**得をする |
| **決済** | 建玉を閉じて、損益を確定させること |
| **証拠金** | 建てるときに預けるポイント。負けたときに失う上限でもある |
| **枚** | 証拠金の単位。1枚＝250pt |
| **倍率** | 値動きを何倍にして損益にするか（1・5・10・25倍） |
| **建玉額** | 証拠金×倍率 |
| **含み損益** | 今決済したら確定する損益 |
| **ロスカット** | 損が証拠金に達したときに、自動で決済されること |
| **自動利確** | 利益が証拠金の5倍に達したときに、自動で決済されること |

# 4. 銘柄

| 銘柄 | 1日の荒さ | 開くコマンド |
| :--- | :--- | :--- |
| **農家** | 3%（おだやか） | :command[/fx farmer] または :command[/fx 農家] |
| **鉱夫** | 15% | :command[/fx miner] または :command[/fx 鉱夫] |
| **冒険家** | 50%（とても荒い） | :command[/fx adventurer] または :command[/fx 冒険家] |

「1日の荒さ」は、1日でどのくらい大きく動きやすいかの目安です。荒い銘柄ほど、すぐにロスカットや自動利確に届きます。

# 5. 画面の使い方

## メインメニュー

:::command
/fx
:::

| 場所 | 内容 |
| :--- | :--- |
| **上の本** | 自分の職業ポイント、預けている証拠金（上限まであといくらか）、今日建てた証拠金、取引の期間 |
| **中ほどの銘柄** | 現在値・前日比・1日の荒さ。建玉がある銘柄は光ります。クリックすると銘柄の画面が開きます |
| **その下の染料** | 自分の建玉（緑が買い、赤が売り）。建てた値・含み損益・ロスカットの値・自動利確の値を確認できます |
| **左下の金インゴット** | 損益ランキング |
| **下の真ん中のエンダーアイ** | 画面右の含み損益の表示・非表示の切り替え |
| **右下のバリア** | 閉じる |

### 建玉を1つだけ決済する

建玉（染料）をクリックすると「もう一度クリックで決済します」と表示されます。5秒以内にもう一度クリックすると決済されます。押し間違いで損が確定してしまわないようにするための仕組みです。

## 銘柄の画面

銘柄をクリックすると、製図台の形をした画面が開きます。画面のタイトルには銘柄名・現在値・前日比が表示され、数秒ごとに更新されます。

| 場所 | 内容 |
| :--- | :--- |
| **左上の地図** | 画面の右側に大きくチャートが表示されます。クリックすると「注文の条件」の画面が開きます |
| **左下のブロック** | クリックするたびに操作が切り替わります（緑＝買い、赤＝売り、金ブロック＝決済） |
| **右の枠** | 選んだ操作を実行します |

右の枠にカーソルを合わせると、建てる前に次の内容を確認できます。

* 証拠金と建玉額
* 手数料と、実際に引かれるポイント
* ロスカットになる値と、自動利確になる値
* 建てられない場合は、その理由（赤い文字）とバリアのアイコン

| 操作 | 方法 |
| :--- | :--- |
| **初めて建てる** | 右の枠を1回クリックすると、すぐに建ちます |
| **同じ向きで買い増し・売り増し** | 確認のため、5秒以内に2回クリックします |
| **決済** | 右の枠をクリックすると、<span class="text-red">**その銘柄の建玉がすべて**</span>決済されます（1回で実行されます） |

※ 建玉を1つだけ決済したいときは、メインメニューから決済してください。

※ すでに建玉がある銘柄では、反対の向きは選べません（「買い」を持っている場合、「売り」は表示されません）。

## チャートの見方

* 緑の足は値が上がった時間、赤の足は下がった時間です。
* 上の数字は表示範囲の高値、下の数字は安値、黄色は現在の値です。
* その銘柄の建玉があると線が表示されます（**青＝建てた値、紫＝ロスカット、水色＝自動利確**）。表示範囲の外にある線は表示されません。
* 足の長さは、1分足・5分足・15分足・1時間足から選べます。

## 注文の条件

左上の地図をクリックすると開きます。

| 行 | 選べるもの |
| :--- | :--- |
| **1行目** | 倍率（1・5・10・25倍）。それぞれ「何%逆に動くとロスカットになるか」と手数料が表示されます |
| **2行目** | 証拠金（1・2・4・8・16枚＝250・500・1,000・2,000・4,000pt） |
| **3行目** | チャートの足の長さ |

選んだ条件は保存され、次に開いたときもそのまま使われます。最初は「1倍・1枚・5分足」になっています。

## 画面右の含み損益

建玉がある間は、画面の右に「FX 含み損益」が表示され、建玉ごとの含み損益と合計を確認できます。表示が不要なときは、メインメニューのエンダーアイで消すことができます（もう一度クリックすると表示されます）。

# 6. ポイントの増減

| タイミング | ポイントの動き |
| :--- | :--- |
| **建てるとき** | 証拠金＋手数料が引かれる |
| **決済するとき** | 証拠金＋損益が戻ってくる |

* 手数料は**建玉額の0.15%**で、建てるときに1回だけかかります。
* 損益は、値動きが小さいうちは、ほぼ「**建玉額×値の変化率**」になります。

## 例：1枚（250pt）・10倍で、1,000.00のときに買った場合

| 項目 | ポイント |
| :--- | :--- |
| 建玉額 | 250×10＝2,500pt |
| 手数料 | 2,500×0.15%＝3.75pt |
| 引かれるポイント | 253.75pt |

| その後の値 | 損益 | 戻ってくるポイント |
| :--- | :--- | :--- |
| 1,020.00（+2%） | 約+49.5pt | 約299.5pt |
| 980.00（−2%） | 約−50.5pt | 約199.5pt |
| 904.84まで下がる（ロスカット） | −250pt | 0pt |
| 1,648.72まで上がる（自動利確） | +1,250pt | 1,500pt |

売りの場合は、値が上がると損、下がると得になります。

::::details{title="上がったときと下がったときで損益が少し違う理由"}
同じ2%の値動きでも、上がったときと下がったときで損益が少し違うのは、損益の計算に対数を使っているためです。こうすることで、買いと売りのどちらかが有利・不利になることがありません。
::::

# 7. 倍率とロスカット・自動利確

倍率を上げるほど、少しの値動きで大きく増減し、すぐに決着がつきます。建てた値からどれだけ動くと自動で決済されるかの目安は、次のとおりです。

| 倍率 | 買い：ロスカット | 買い：自動利確 | 売り：ロスカット | 売り：自動利確 | 手数料（1枚） |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **1倍** | 約63%下がる | 約148倍に上がる | 約172%上がる | 約99%下がる | 約0.4pt |
| **5倍** | 約18%下がる | 約172%上がる | 約22%上がる | 約63%下がる | 約1.9pt |
| **10倍** | 約9.5%下がる | 約65%上がる | 約10.5%上がる | 約39%下がる | 3.75pt |
| **25倍** | 約3.9%下がる | 約22%上がる | 約4.1%上がる | 約18%下がる | 約9.4pt |

* 1倍では、自動利確はまず起きません。利益は自分で決済して確定させてください。
* 正確な値は、建てる前は右の枠で、建てた後はメインメニューの建玉で確認できます。
* <span class="text-red">**ロスカットと自動利確は、ログアウト中でも起きます。**</span>

# 8. ルール

| 項目 | 内容 |
| :--- | :--- |
| **同時に預けられる証拠金** | 1人4,000pt（16枚）まで |
| **1日に新しく建てられる証拠金** | 1人10,000ptまで。毎日0時にリセットされます。勝って戻ってきたポイントで建て直した分も数えます |
| **同じ銘柄の買いと売り** | 同時には持てません。反対の向きにしたいときは、先に決済してください |
| **買い増し・売り増し** | 同じ向きで建て増すと、別の建玉として増えます（建てた値・ロスカットの値もそれぞれ別になります） |
| **期間の終わり** | 残っている建玉は、その時点の値で自動的に決済されます |

# 9. ログアウト中・サーバー停止中

* 値はログアウト中も動き、ロスカットや自動利確も起きます。
* ログアウト中に決済された建玉のポイントは、**次にログインしたとき**に戻ってきます。チャットに「ログアウト中に閉じた建玉があります」と結果が表示されます。
* サーバーが止まっている間は値も止まり、再開すると続きから動きます。

# 10. 値動きの仕組み

値が上がるか下がるかは**乱数だけ**で決まります。元の値に戻ろうとする力も、値の上限・下限もありません。

ただし、値の動きやすさ（荒さ）は時間帯によって変わります。

| 時間帯 | 荒さ |
| :--- | :--- |
| **2時〜8時** | おだやか |
| **8時〜20時** | ふつう |
| **20時〜2時** | 荒め |

荒さはゆっくり波を打つように変わり、1日に数回、**30秒ほど急に荒くなる**ことがあります。時間帯や急変があっても、1日全体で見ると銘柄ごとの「1日の荒さ」になるように調整されています。

| 出来事 | 通知 |

| **建てた・決済した・ロスカット** | 本人にだけ、チャットと音で知らせます |

# 12. ランキングと職業の累計ポイント

* メインメニューの損益ランキングは、**決済した損益の合計**（手数料を引く前）の順に並びます。上位10人と、自分の順位を確認できます。
* 職業の累計ポイント（[実績](/adventure/achivements)などの条件になる値）には、**勝った分の利益だけ**が加算されます。戻ってきた証拠金は加算されず、負けても累計は減りません。

# 13. 建てられないとき

右の枠に、赤い文字で理由が表示されます。

| 表示される文字 | 対処方法 |
| :--- | :--- |
| まだ取引の期間が始まっていません | 期間が始まるまでお待ちください。チャートは見ることができます |
| 取引の期間は終わりました | 取引の期間が終わっています |
| この銘柄は反対の向きで建てています。先に決済してください | 反対の向きの建玉を決済してから建ててください |
| 同時に預けられる証拠金の上限を超えます | 証拠金を減らすか、ほかの建玉を決済してください |
| 今日建てられる証拠金の上限を超えます | 翌日0時まで待つか、証拠金を減らしてください |
| Jobs ポイントを読み込めません。少し待ってからやり直してください | ログインした直後に表示されることがあります。少し待ってからやり直してください |
| Jobs ポイントが足りません | 証拠金＋手数料の分のポイントが必要です。証拠金か倍率を下げてください |

# 14. コマンド一覧

| コマンド | 説明 |
| :--- | :--- |
| :command[/fx] | メインメニューを開きます。 |
| :command[/fx <銘柄>] | 銘柄の画面を直接開きます。銘柄は farmer・miner・adventurer、または 農家・鉱夫・冒険家 で指定します。 |

***
値動きによる損益は、平均すると±0になるように作られています。ただし建てるたびに手数料がかかるため、長く続けるほど、平均では**手数料の分だけポイントが減っていきます**。勝つときもあれば負けるときもある遊びとして楽しんでください。なくなって困るポイントは使わないようにしましょう。
